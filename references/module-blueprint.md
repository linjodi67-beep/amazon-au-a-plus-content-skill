# Module blueprint

Use this blueprint as the default layout map for Amazon Australia A+ Content.

## 1. Hero

- Desktop: product cutout on left or right; product/model should be large, usually 60-85% of canvas height; bold headline opposite; 2-3 badges.
- Mobile: product/model should still feel like the main subject, usually 65-90% of canvas height; headline limited to 2-4 lines.
- Include: product name, brand, item number if useful.
- Never place headline/body text on top of the product/model.

## 2. Benefit icons

Use four short cards:

- Conversation starter / standout theme
- Photo-ready look
- Easy dress-up or easy styling
- Occasion fit

Keep each body line under about 12 words for mobile readability.

## 3. Multi-angle view

Use front, side, and back photos in equal cards. Do not skew perspective. Label clearly.

## 4. What's included

Use checklist format. Include only supplied contents. Add "wear with your own basics" only as a styling tip, not as included contents.

## 5. Close-up details

Use real crops from supplied photos when possible:

- Print / texture
- Fastening / back / construction
- Packaging or material close-up if supplied

Do not add decorative full-body model cutouts if they crowd or overlap the detail captions. Keep close-up cards and text fully readable.

## 6. Size / pack guide

Use supplied facts:

- Packaged dimensions
- Packaged weight
- Pack quantity / contents

If garment sizing is missing, avoid sizing claims.
Keep GTIN/barcode out of the visual by default unless the user explicitly requests it.

## 7. Comparison chart

Compare shopper use-cases or category types, not unsupported quality claims. Good columns:

- This product
- Animal costume
- Classic character costume

Good rows:

- Theme fit
- Photo moment
- Easy styling
- Occasion match

## 8. Brand story

Use 2-3 short lines plus fact badges. For Tomfoolery, make the story consumer-friendly:

- "Established 1962"
- "Wholesale heritage"
- "Now on Amazon"

Use wording that builds confidence: Tomfoolery has long supplied Australian and New Zealand retailers, and now brings selected party/costume favourites directly to Amazon shoppers. Keep brand story visually calmer than the hero.
